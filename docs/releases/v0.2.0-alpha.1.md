# Tungaon v0.2.0-alpha.1 — Guided splitting and better receipt parsing

This feature update adds guided item assignment and visible people avatars, alongside the receipt-parsing improvements since v0.1.0-alpha.2. The minor version increases to 0.2.0 for the expanded splitting workflow; it remains a **debug-signed alpha prerelease for testing**, with physical-device and real-dinner validation still outstanding.

## Install or update

Download **tungaon-0.2.0-alpha.1-debug.apk** from Assets on an Android 8.0+ phone. Install it over your existing Tungaon alpha to retain your local ledger. **Do not uninstall first:** backup/import is not available yet.

The application ID and signing certificate match v0.1.0-alpha.2. Android version code increases from 2 to 3. `SHA256SUMS.txt` contains the asset checksums.

## What changed

- Assign one receipt item at a time with Everyone / Just me shortcuts, live shares, and a review before saving.
- See everyone on the receipt as named avatar bubbles, with You / Paying and explicit Add people / Edit people actions. Attendance remains separate from who had each item.
- Avatar rows wrap for narrow phones and larger system text. An empty item selection blocks progression without replacing the last valid assignment.
- Better handling of multi-line items, quantities and unit prices, skewed price columns, small receipt images, and observed tax/total label variants.
- Existing split calculations, rounding, ledger storage and draft recovery are preserved. Rescan or reimport old receipts to apply the parser improvements.

## Verification

- Clean source build: 60 JVM tests and 18 Android emulator tests passed.
- Debug APK built; Android lint reported 0 errors and 30 warnings.
- APK signatures verified; signer certificate matches the previous published APK, whose checksum was independently checked.
- Native avatar layouts inspected at standard width, 320dp width and 1.8× text with a long name during UI verification.

## Known limitations

This is not a production-signed stable release. No backup/import is available; uninstalling or clearing app data can lose the ledger. OCR still needs manual review of names, items and totals; limited receipt samples do not establish broad accuracy. Physical camera/scanner behavior, TalkBack, reboot/background reminders and real collection outcomes need further field testing. The app remains English/PHP; Google Play services may require a first-use scanner download.
