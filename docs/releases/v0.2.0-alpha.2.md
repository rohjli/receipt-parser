# Tungaon v0.2.0-alpha.2 — Clearer balances and payments

This alpha update includes the merged [Clear sections design (#2)](https://github.com/rohjli/receipt-parser/pull/2). It remains a **debug-signed prerelease for testing**.

## Install or update

Download **tungaon-0.2.0-alpha.2-debug.apk** from Assets on an Android 8.0+ phone. Install it over your existing Tungaon alpha to retain your local ledger. **Do not uninstall first:** backup/import is not available yet.

The application ID and signing certificate match v0.2.0-alpha.1. Android version code increases from 3 to 4. `SHA256SUMS.txt` contains the asset checksums.

## What changed

- Separate **Owe you**, **You owe**, and **No balance** sections make each person's balance easier to understand, with a count of people in each group.
- Outstanding amounts have a clear **Record payment** action. Record a partial or full payment with the existing date, note and Undo behavior.
- **No balance** starts expanded, with compact rows that keep each person's history accessible. Its expanded or collapsed state is preserved.
- Larger system text stacks amounts to keep the cards readable.
- Existing ledger calculations, stored data and database schema are unchanged.

## Verification

- Clean checkout of the merged code with the release version bump: 60 JVM tests and all 5 ClearBalanceSectionsTest emulator tests passed.
- Debug APK built; Android lint reported 0 errors and 30 warnings. The first device-test attempt was interrupted when the emulator exited; all 5 tests passed after restarting it without wiping data.
- APK signature verified; signer certificate matches the previous published APK, whose checksum was independently checked.
- Tests cover balance grouping, archived-person history, saved disclosure state, partial/full payments and repository Undo, failed-save input retention, and 1.8× text.

## Known limitations

This is not a production-signed stable release. No backup/import is available; uninstalling or clearing app data can lose the ledger. The full pre-existing device test suite was not rerun for this release. Production Snackbar tapping, TalkBack traversal and physical-device behavior were not newly tested. OCR still requires manual review; limited receipt samples do not establish broad accuracy. The app remains English/PHP; Google Play services may require a first-use scanner download.
