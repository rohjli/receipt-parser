# Tungaon v0.1.0-alpha.2 — A new name and a fresh interface

Tab is now **Tungaon**, with the emerald-and-rose shared-receipt logo and a redesigned native Android interface. This remains a **debug-signed prerelease for testing**.

## Install or update

Download **tungaon-0.1.0-alpha.2-debug.apk** from Assets on an Android 8.0+ phone. Open the APK and allow installation from that app if Android asks. Choose the APK rather than the source-code archives.

Install over the previous alpha to retain your ledger. The application ID and signing certificate match alpha.1; the version code increases from 1 to 2. The displayed version is `0.1.0-alpha.2`. **Do not uninstall first:** there is no backup/import yet. `SHA256SUMS.txt` contains the APK checksum.

## What changed

- Tungaon name and shared-receipt logo, including adaptive/themed Android launcher icons and updated receipt exports.
- Rounded white surfaces, an emerald balance card, rose scan accents, and pastel friend shortcuts that open their actual history.
- A receipt-viewfinder illustration and clearer scan/photo/manual actions. Scanning still uses the working Google ML Kit scanner.
- Fixed correction/save actions and a people-picker sheet for assigning selected items without scrolling back to the top.
- Clearer payment/history presentation, settings sections, selection states, and layouts for larger system text.
- Existing money calculations, stored ledger data, draft recovery and sharing behavior are preserved.

## Verification

- Debug build, 24 JVM tests and 9 Android emulator tests passed.
- Android lint: 0 errors, 29 advisory warnings.
- Normal phone and narrow 320dp / 200% text layouts inspected.
- APK signature verified against the original alpha.1 release certificate.

## Known limitations

No backup/import: uninstalling, clearing app data or losing the phone can lose the ledger. Real-receipt OCR accuracy remains unproven; review recognized items and totals. Camera quality, TalkBack, physical-device keyboard behavior, reboot/background reminders and real collection outcomes still need field testing. Google Play services may need a first-use scanner download; gallery and manual entry remain available. Reminders are approximate, very long PNG exports are capped, and the interface/currency remain English/PHP. GenAI cleanup and per-receipt nudge text remain future work.
